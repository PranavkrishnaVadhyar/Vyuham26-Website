5. ISSUES RESOLVED DURING PRE-DEPLOYMENT AUDIT
================================================================================

1. Issue: Missing `GET /admin/stats` endpoint.
   Root Cause: SQLAdmin was mounted at `/admin`, but no REST statistics route existed.
   Fix: Implemented `GET /admin/stats` in `app/modules/admin/router.py` with live
   aggregation across registrations, payments, checkins, and events.
   Removed mock fallback numbers.

2. Issue: `POST /events/{event_id}/results` failed with 422 for slug identifiers.
   Root Cause: Route parameter expected UUID only.
   Fix: Changed `event_id` to `str`, allowing both UUID and slug lookups.

3. Issue: Repeated `GET /announcements` request storm on page transitions.
   Root Cause: Independent component mounts polled without caching.
   Fix: Added 15-second TTL cache and in-flight promise deduplication in `api.ts`.

4. Issue: Direct browser page refresh on static hosting could return 404.
   Root Cause: Missing SPA rewrite rules.
   Fix: Added `vercel.json` SPA catch-all rewrite rule to `/index.html`.

5. Issue: Missing `favicon.ico` in static web root.
   Root Cause: File was located in `src/pages/` instead of `public/`.
   Fix: Relocated `favicon.ico` to `public/favicon.ico` and linked in `index.html`.

6. Issue: Missing Docker container deployment configuration for backend.
   Root Cause: No production Dockerfile.
   Fix: Created production `Dockerfile` and `.dockerignore` for Python 3.12-slim.
