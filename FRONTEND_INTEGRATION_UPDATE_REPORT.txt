1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
The Vyuham'26 web platform has been fully overhauled and upgraded to establish a
seamless, production-ready integration between the frontend client
(`Vyuham26_frontend` — React 19, TypeScript, Vite) and the backend API server

All split-brain state issues, placeholder registrations, and disconnected forms
have been unified and wired to typed REST endpoints with automatic Bearer token
injection, multi-role authorization, and graceful offline fallback handling.

--------------------------------------------------------------------------------
2. SYSTEM ARCHITECTURE & INTEGRATION SPECIFICATION
--------------------------------------------------------------------------------
Frontend Stack:
  - Framework: React 19 (Vite + TypeScript)
  - Styling: Tailwind CSS + Cyberpunk Glassmorphism Design System
  - Authentication: Supabase Auth (Session, JWT Tokens) + AuthContext
  - Networking: src/lib/api.ts (Fetch wrapper with Bearer token injection)
  - Audio: CyberAudio Web Audio API Synthesizer

Backend Stack:
  - Gateway: FastAPI (Python 3.11+, Uvicorn)
  - Database: PostgreSQL (Supabase-managed) with SQLAlchemy asyncpg
  - Auth Middleware: Supabase JWT validation & get_current_user dependency
  - Routers: /auth, /events, /registrations, /teams, /payments, /checkin, /admin, /announcements

Security & Role Matrix:
  - Roles supported: "user" (participant), "volunteer", "event_head", "admin"
  - Token Handling: Injected dynamically into "Authorization: Bearer <token>"
  - Role Normalization: Backend "participant" automatically normalizes to "user"
